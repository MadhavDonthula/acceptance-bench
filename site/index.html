Same 6 captured sessions replayed against every arm with original inter-call gaps and a fresh affinity id. With agent behavior held fixed, the speed/cost tradeoff persists — it is inference-level, not just "Coral reasons more."

Why the cost gap?

  • 65% of the cost gap is token / cache behavior (Baseten bills far more uncached input — lower cache hit).
  • 35% is unit price. Even priced at Coral's rates, Baseten's tokens cost more.

How it's measured

  • Every request flows through a local recording proxy (added overhead: 2.23 ms/call, both arms).
  • Identical settings injected on both arms: temperature 0, max_tokens 8192, reasoning_effort high.
  • Deterministic judge: 7 prioritized hidden tests, acceptance = all pass; mutation-tested.
  • Cost at public list prices with cache discount (verified against provider billing).

Limitations

  • One task (payments idempotency), one machine/region — CIs quantify run-to-run variance, not external validity.
  • Snapshot identity: Coral serves an opaque snapshot; running both Baseten snapshots (B,C) showed no robust snapshot difference, but Coral-vs-Baseten weights identity is unconfirmed.
  • Coral documents FP4 serving; Baseten precision undisclosed — token-for-token quality may differ.
